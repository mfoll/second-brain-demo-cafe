# Should We Set Aside VAT Weekly?

Should we move VAT into a separate account as we collect it, rather than paying it from the current account each quarter?

## Current Answer

Yes, since 2025-03-10. Every Monday, 9% of the previous week's gross takings goes into the Pellow Mutual savings account we call the VAT pot. The quarterly payment comes out of the pot. [[ruth-marchbank]] suggested it in February 2025 after the [[overdraft-squeeze-january-2025]].

Why 9%: our blended VAT across reduced-rate food and standard-rated drinks, less input VAT on purchases, has run at 8-9.5% of gross takings. The pot has covered every quarter since, with between 200 and 900 EUR left over, which stays as a small cushion.

Rejected: monthly transfers (too easy to skip in a busy month) and moving exactly the output VAT from Xero each week (more precise, more work, same result).
