# Do We Need A Second Label Printer

Should we buy a second label printer for the pass, in case the first fails or the Christmas rush outgrows it?

## Current Answer

No. One printer covers normal volume (about 70 labels a day) and the December 2025 peak (about 260 a day) with time to spare. If it fails, the template prints on A4 label sheets from the office printer, which we tested in November 2025. A spare costs 289 EUR; the fallback costs nothing.

## Revisit if

Christmas preorders 2026 reach the 320 target and need labelled boxes on the same morning ([[christmas-preorders-2026]]). Lena will time the 2026 rush.
