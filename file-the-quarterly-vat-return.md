# File The Quarterly VAT Return

How the quarterly VAT return is prepared and filed from Xero, and paid from the VAT pot. Written after the [[first-xero-vat-return-2025-07-28]]. Due dates are in the [[vat-return-calendar]]; we aim to file three days early.

## Before You Start

- Quarter fully reconciled in Xero, including the last day's Square import.
- All supplier bills for the quarter entered. Chase missing ones (Glenvarrow and Brook & Daughters send theirs late).
- For Q2 and Q4: book the review with [[ruth-marchbank]]'s team ten days before the deadline.

## Steps

1. In Xero, open the VAT return for the quarter.
2. Check sales by tax rate: drinks at the standard rate, food at the reduced rate. If the drinks share looks very different from last year's same quarter, check the Square category mapping ([[square-to-xero-daily-import-settings]]).
3. Check purchases for bills with no VAT code; fix them.
4. Compare the liability to the VAT pot balance. A difference over 1,000 EUR needs an explanation before filing.
5. For Q2 and Q4, send the draft to Ruth's team and wait for their OK.
6. File from Xero. Save the submission receipt as PDF in Finance/VAT/<year>-Q<n>.
7. Schedule the payment from the VAT pot for two working days before the due date.
8. Update the forecast: remove the estimate, enter the actual ([[update-the-cash-flow-forecast]]).
9. Leave any surplus in the pot as cushion.

## Guardrails

Never pay VAT from the current account if the pot is short; top up the pot first, so the shortfall is visible ([[vat-money-is-not-our-money]]).
